Editar la tienda

Cambiá productos, precios, fotos y textos y tocá Guardar cambios. La tienda se actualiza en 1 o 2 minutos.

Conectá GitHub para poder guardar

Se hace una sola vez en cada celu o compu. El token queda guardado solo en este dispositivo.

Cómo sacar el token
  1. Entrá a GitHub con la cuenta osomates8-sys y abrí este link.
  2. Nombre: "Editor tienda". Vencimiento: el que quieras (por ejemplo 1 año).
  3. En Repository access elegí Only select repositories y marcá oso-mates.
  4. En Permissions → Repository permissions → Contents: Read and write.
  5. Tocá Generate token, copialo y pegalo acá arriba.
✓ Conectado a GitHub. Los datos se cargaron directo del repo, así que siempre ves la última versión.

Guardar a mano (sin token)
  1. Tocá Generar archivo.
  2. Tocá Copiar.
  3. Abrí el link a GitHub, borrá todo el contenido del archivo y pegá lo copiado.
  4. Abajo de todo en GitHub, tocá Commit changes.

Ojo: de esta forma las fotos nuevas quedan metidas adentro del archivo y lo hacen pesado. Con el botón Guardar cambios se suben como archivos aparte.
